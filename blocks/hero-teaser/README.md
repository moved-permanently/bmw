# hero-teaser

Full-bleed background image or video with overlaid headline, text and CTAs; desktop: text over the media with optional gradient; mobile/tablet: text below the media overlapping it with a fade to black.

## Authoring (Document Authoring)

Row 1 (media): desktop image, mobile image[, tablet image] - or poster images + desktop/mobile video links. Row 2 (content): heading(s) (first = headline, further = subsection), paragraphs, CTAs.

## Options

`center`, `end`, `top`, `middle`, `bottom`, `text-width-<fraction>`, `text-above-<size>`, `text-below-<size>`, `subline-above-<size>`, `cta-above-<size>`, `cta-below-<size>`, `cta-stack-md`, `gradient-left`, `gradient-oblique`, `gradient-top`, `gradient-right`, `gradient-bottom`, `contained`, `ai-label`, `no-autoplay`, `loop`, `no-play-button`, `ratio-W-H`, `mobile-ratio-W-H`

Sizes and fractions: [section and block styles](../../docs/authoring/section-and-block-styles.md).
